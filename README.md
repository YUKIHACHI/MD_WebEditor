# Markdown Editor

ローカルで動く `.md` / `.markdown` 用のMarkdownエディターです。

## 起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173/` を開きます。

## 主な機能

- `.md` / `.markdown` ファイル読み込み
- Markdown編集とリアルタイムプレビュー
- GitHub風Markdownとテーブル記法
- `.md` 保存
- 見出し、太字、斜体、コード、リスト、引用、テーブル挿入
- エディタ / プレビュー / 分割表示切替
- 文字数、単語数、行数表示
- タブ式の複数ファイル編集
- `localStorage` によるローカル自動保存
- 検索・置換
- ダークモード
- HTML出力
- PDF出力用の印刷画面表示
