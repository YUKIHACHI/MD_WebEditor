# Markdown Editor

ローカルで動く `.md` / `.markdown` 用の Markdown エディターです。  
複数ファイルをタブで切り替えながら編集でき、リアルタイムプレビュー、ローカル自動保存、検索・置換、ダークモード、HTML/PDF出力に対応しています。

## 使い方

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173/` を開いてください。

## 機能

- `.md` / `.markdown` ファイル読み込み
- Markdown編集とリアルタイムプレビュー
- GitHub風Markdownとテーブル記法の表示
- `.md` として保存
- 見出し、太字、斜体、コード、リスト、引用、テーブルの挿入
- エディタ / プレビュー / 分割表示の切り替え
- 文字数、単語数、行数の表示
- タブ式の複数ファイル編集
- `localStorage` を使ったローカル自動保存
- 検索・置換
- ダークモード
- HTML 出力
- PDF 出力用の印刷画面表示

## 補足

- ファイルメニューは右クリックで新規作成メニューを開けます。
- ツールバーの挿入操作は `Ctrl+Z` で戻せます。
